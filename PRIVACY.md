# Privacy policy

The Ruvio skills plugin contains only instructions and documentation text (`SKILL.md` files) and an icon. It has no code, no MCP servers and no hooks.

- It does not collect, store or send any personal data or usage data.
- It does not contact any service on its own. When the assistant follows a link in a skill, it reads public documentation pages on ruviodb.com; those requests are made by the assistant you use, under that assistant's own privacy terms.
- The Ruvio server and clients you run are your own software on your own machines; this plugin does not connect to them.

Questions: open an issue at https://github.com/salihcantekin/ruvio-skills/issues.
